# Cipher Match 成长与付费数值审计

## 范围

- 本次审计范围：`game7 / games/cipher-match`
- 审计目标：
  - 检查从新手到核心玩家的成长线是否连续
  - 检查推荐战力、资源产出、升级消耗是否匹配
  - 检查付费后资源与战斗参数的变化是否合理

## 一、基础结论

### 1. 成长主线整体是通的

- 新手期依靠：
  - 默认资源
  - 新手保护
  - 首章 Boss 缓冲
- 中期依靠：
  - 卡牌等级
  - `stabilityMesh` 研究乘区
  - 任务 / 赛季 / 每日补给
- 后期依靠：
  - 构筑优化
  - 研究等级
  - Boss 专项能力

### 2. 最终推荐战力和满配上限基本对齐

- 当前最终关卡推荐：`1440`
- 理论最优满配战力：`1446`
- 默认初始构筑满配战力：`1400`

这说明：

- 核心玩家最终需要“接近毕业 + 正确构筑”才能踩线通关
- 不会出现数值天花板明显高于最终关卡，导致后期完全失压
- 也不会出现满配仍远低于终局推荐线，导致终局不可达

## 二、成长线拆解

### 1. 起始状态

- 默认存档资源：
  - `credits = 1680`
  - `keyBits = 180`
  - `cipherDust = 56`
- 默认构筑：
  - `leader = glintFox`
  - `modules = prismTap + hardPatch`
  - `skill = gridBurst`
- 默认构筑初始战力：`260`
- 当前可切换的最强初始构筑战力：`293`

### 2. 推荐战力曲线

| 关卡 | 推荐战力 | 相邻增量 | 相邻增幅 |
| --- | ---: | ---: | ---: |
| `1-1` | 180 | 0 | 0% |
| `1-2` | 270 | 90 | 50.0% |
| `1-3` | 400 | 130 | 48.1% |
| `2-1` | 520 | 120 | 30.0% |
| `2-2` | 650 | 130 | 25.0% |
| `2-3` | 780 | 130 | 20.0% |
| `3-1` | 900 | 120 | 15.4% |
| `3-2` | 1030 | 130 | 14.4% |
| `3-3` | 1160 | 130 | 12.6% |
| `4-1` | 1260 | 100 | 8.6% |
| `4-2` | 1360 | 100 | 7.9% |
| `4-3` | 1440 | 80 | 5.9% |

### 3. 这条曲线的实际体验判断

#### 新手期：`1-1 ~ 1-3`

- 从纸面看，增幅非常陡
- 但实际体验被三层缓冲吃掉了：
  - 默认资源足够先做一轮完整升级
  - 新手保护给额外步数 / 能量 / Boss 缓冲
  - 默认构筑本身带 `hardPatch`

结论：

- **纸面很陡，体验不陡**
- 这段是合理的，不需要大砍推荐战力

#### 熟练过渡期：`2-1 ~ 2-3`

- 开始要求玩家不只升级，还要理解：
  - 双色目标
  - 护盾机制
  - 技能释放时机
  - 基础构筑切换

结论：

- 这段是当前最自然的“从新手转熟练”的区间
- 真正的第一处中期卡点是 `2-2 / 2-3`
- 这也是季票和中档成长包最容易体现价值的位置

#### 核心前置期：`3-1 ~ 3-3`

- 数值开始要求：
  - 研究乘区
  - Boss 专项能力
  - 更优构筑
  - 更稳定的开局资源

结论：

- `3-3` 是当前第一处真正的硬卡点
- 这里作为核心玩家门槛是合理的
- 但如果付费加成过重，会直接把这段压扁

#### 核心期：`4-1 ~ 4-3`

- 数值增长放缓
- 重点从“继续堆基础值”转向：
  - 研究完成度
  - Boss 控制能力
  - 构筑细节

结论：

- 终局推荐线设计是好的
- 终局不是纯堆数值，而是“数值 + 构筑”双要求

## 三、资源与升级合理性

### 1. 默认资源能推到哪里

把默认构筑的 4 张出战卡同步升到同一等级时：

| 默认构筑整体等级 | 总消耗 Credits | 总消耗 Bits | 构筑战力 |
| --- | ---: | ---: | ---: |
| `Lv2` | 610 | 74 | 336 |
| `Lv3` | 1407 | 163 | 412 |
| `Lv4` | 2449 | 269 | 488 |
| `Lv5` | 3812 | 396 | 564 |
| `Lv6` | 5594 | 548 | 640 |
| `Lv7` | 7926 | 732 | 716 |
| `Lv8` | 10979 | 951 | 792 |

默认存档资源允许玩家：

- **直接把默认出战构筑拉到 `Lv3`**
- 对应战力：`412`
- 这已经超过 `1-3` 推荐线 `400`

结论：

- 新手首章不会被硬卡
- 这一点是合理的

### 2. 长线资源门槛是谁

#### `credits`

- 全章节基础奖励总和：`16530`
- 加首通奖励总和：`27707`
- 默认出战构筑满级总消耗：`26407`

判断：

- `credits` 在前中期是压力
- 但到了中后期，它不是最硬的门槛
- 因为过关本身的 `credits` 回流是持续正向的

#### `keyBits`

- 全章节基础奖励总和：`2066`
- 加首通奖励总和：`3147`
- 默认出战构筑满级总消耗：`1848`
- 全部卡牌满级总消耗：`5239`

判断：

- `keyBits` 足够支撑玩家养成一套主力构筑
- 但不足以支撑“全卡毕业”
- 这条线是合理的

#### `cipherDust`

- 全章节基础奖励总和：`666`
- 加首通奖励总和：`1067`
- 全研究毕业总消耗：`2716`

判断：

- `cipherDust` 才是当前最硬的长期门槛
- 这对留存是有利的
- 但如果你希望非付费玩家在 `3-3 ~ 4-3` 之间更顺滑，当前 `dust` 压力偏高

## 四、付费后的数值变化是否合理

## 1. Starter Pack

### 包内容

- 资源：
  - `credits +2600`
  - `keyBits +220`
  - `cipherDust +72`
- 永久效果：
  - 每日免费局 `+1`
  - 每局额外 `+1` 步
  - 每局额外 `+18` 能量
  - 继续购买价格额外 `-12%`

### 资源换算

- 相当于：
  - `1-3` 的 `6.7` 倍 `credits`
  - `1-3` 的 `4.4` 倍 `bits`
  - `1-3` 的 `4.0` 倍 `dust`

### 对成长线的实际影响

- `Base Save + Starter` 可把默认构筑拉到：
  - **完整 `Lv5`**
  - 对应战力：`564`

这条线刚好压在：

- 高于 `2-1` 推荐线 `520`
- 低于 `2-2` 推荐线 `650`

结论：

- **Starter 包的资源定位是合理的**
- 它非常准确地对应了 `1-3 / 2-1` 的软卡点

### 风险点

- 永久 `+18` 能量偏强
- 它不是“早期好用”，而是“全程都好用”

建议：

- 保留 `+1` 步
- 把永久 `+18` 能量调到 `+10 ~ +12`
- 或者把 `+18` 能量限制在 `Chapter 1~2`

## 2. Season Pass

### 包内容

- 直接到账：
  - `credits +4200`
  - `keyBits +320`
  - `cipherDust +160`
  - `seasonXp +180`
- 永久效果：
  - 解锁高级赛季轨道
  - 研究价格 `-15%`
  - `Chapter 3+` 额外 `+1` 步
  - `Chapter 2+` 额外 `+10 / +14` 开局能量
  - `Chapter 3+` 大消除额外推进 `+1`
  - `Chapter 3+ Boss` 反制再放慢，抽能更低
  - `Chapter 3+` 奖励 `+5%`

### 高级赛季轨道总值

- 高级轨道总奖励：
  - `credits +11020`
  - `keyBits +822`
  - `cipherDust +200`

### 季票真实总值

- 季票首购 + 高级轨道合计：
  - `credits +15220`
  - `keyBits +1142`
  - `cipherDust +360`

### 对成长线的实际影响

- `Base Save + SeasonPass` 本身也能把默认构筑拉到：
  - **完整 `Lv5`**
  - 战力：`564`

单看直充资源，它和 Starter 一样，主要压的是 `2-1`

但它的问题不在首充资源，而在“叠加值过多”：

- 研究折扣
- 高级赛季奖励
- 开局资源
- 战斗推进
- Boss 反制缓和
- 奖励增产

结论：

- **Season Pass 当前是“资源包 + 成长包 + 战斗包 + 赛季包”四合一**
- 价值过满
- 对 `2-2 / 2-3 / 3-1` 会产生明显压扁

建议：

- 二选一：
  - 保留“高级赛季轨道 + 研究折扣”
  - 或保留“高级赛季轨道 + 轻度开局加成”
- 不建议继续同时保留现在这一整套战斗强加成

## 3. Breaker Vault

### 包内容

- 直接到账：
  - `credits +18000`
  - `keyBits +1350`
  - `cipherDust +560`
- 永久效果：
  - `Chapter 3+` 奖励 `+18%`
  - `Chapter 4+` 奖励 `+24%`
  - Boss 关额外 `+1` 步
  - Boss 关大消除额外推进 `+2`
  - Boss 反制窗口显著变长
  - Boss 回盾显著变弱
  - Boss 抽能显著变弱
  - 继续购买再 `-12%`

### 资源换算

- 相当于：
  - `3-3` 的 `9.6` 倍 `credits`
  - `3-3` 的 `5.7` 倍 `bits`
  - `3-3` 的 `7.2` 倍 `dust`

### 对成长线的实际影响

- `Base Save + BreakerVault` 可把默认构筑拉到：
  - **完整 `Lv8`**
  - 对应战力：`792`

这已经：

- 高于 `2-3` 推荐线 `780`
- 非常接近 `3-1`

而这还**没算**它的永久 Boss 弱化效果

结论：

- 这个包的“定位”是对的：它确实应该解决 `3-3 / 4-x Boss` 卡点
- 但它的**资源投放 + 永久战斗加成都偏重**
- 如果玩家在前中期就能看到并购买，它会直接破坏前半程成长线

建议：

- 这个包最好：
  - 到 `3-1` 之后再强曝光
  - 或者在 `3-3` 前不作为主推荐包
- 另外建议二选一：
  - 保留大资源，削弱永久 Boss 控制
  - 或保留永久 Boss 控制，下调直充资源到更克制的档位

## 五、当前数值最合理的地方

- 默认起始资源足以确保新手不会在 `1-1 ~ 1-3` 被硬卡
- `2-2 / 2-3` 是很自然的熟练度过渡卡点
- `3-3` 作为第一处硬卡点是成立的
- 最终推荐线 `1440` 和理论毕业线 `1446` 非常工整
- `keyBits` 够养主力，不够养全图鉴，这条设计合理

## 六、当前最需要警惕的问题

### 1. Season Pass 价值过满

- 它不是一个“赛季通行证”
- 它更像“赛季通行证 + 中档成长包 + 研究折扣卡 + 中后期战斗通行证”

这会让非付费玩家在 `2-2 ~ 3-1` 的成长体验落差过大

### 2. Breaker Vault 如果过早出现，会压坏前中期成长线

- 资源量太大
- Boss 永久减压太明显
- 会让 `2-3 ~ 3-3` 的成长价值被直接跳过

### 3. Starter Pack 的永久能量加成偏大

- `+18` 能量不是一次性追赶
- 而是全程稳定强势
- 会长期干扰战斗节奏和技能循环

### 4. Credits 到中后期不是最硬门槛

- 真正卡的是：
  - `keyBits`
  - `cipherDust`

如果后面继续加大付费包里的 `credits`，边际意义会越来越低

## 七、建议调优方向

## 建议 A：保留当前章节推荐线，不先动主线数值

原因：

- 主线推荐线本身并没有崩
- 真正影响体验的是：
  - 新手保护
  - 默认资源
  - 付费永久加成

## 建议 B：削弱 Season Pass 的战斗强度，保留它的赛季身份

建议优先砍：

- `Chapter 3+ progressBonus +1`
- `BossGrace`
- `DrainReduction`

优先保留：

- 高级轨道
- 研究折扣
- 轻度开局能量

## 建议 C：把 Breaker Vault 的主推荐曝光延后

建议：

- `3-1` 之后再主推
- `3-3` 时变成最强推荐

否则它会过早冲穿中段卡点

## 建议 D：Starter Pack 的永久开局能量下调

建议从：

- `+18`

改为：

- `+10 ~ +12`

或仅在前两章生效

## 建议 E：如果要继续做免费线长线，适当补一点中后期 Dust

可选做法：

- 提高 `3-2 / 3-3 / 4-2 / 4-3` 的 `cipherDust`
- 或提高部分免费赛季轨道中的 `dust`

目标不是让免费玩家毕业更快，而是避免 `3-3 ~ 4-3` 完全只剩 `dust` 单点卡死

## 八、额外技术风险

- 当前支付验证逻辑是：
  - 校验 TxID 格式
  - 检查是否重复
  - 然后直接发奖励

这意味着它目前是“本地闭环演示”，不是链上真实校验

对数值的影响是：

- 付费奖励的发放强度本身合理与否是一回事
- 但**奖励发放安全性**仍然是单独风险点

## 审计结论

- **成长线整体合理**
- **新手到熟练的过渡是通的**
- **终局推荐线和理论毕业线对得很漂亮**
- **当前真正不够合理的，是中高档付费包叠加的战斗强度过满**

如果继续下一步，建议直接做：

1. `Season Pass` 战斗加成减法
2. `Breaker Vault` 推荐时机后移
3. `Starter Pack` 永久能量下调
4. `3-3 ~ 4-3` 免费 `dust` 轻补
