# Neon Cards 模块与数值规划

## 目标定位

- 第 6 个游戏默认采用大厅中已预留的 `neon-cards` 方向。
- 中文名：`霓虹卡牌`
- 英文名：`Neon Cards`
- 类型定位：`三路实时卡战 + 拖放出牌 + 卡组养成 + 赛季付费`
- 目标体验：
  - 10 秒内看懂怎么开打
  - 30 秒内出现第一次“拖牌上场 / 技能反打”的爽点
  - 3 分钟内形成“再打一局 / 再升一张卡”的驱动力
  - 1~2 天内形成“免费可玩，但充值会明显加速卡组成型”的体感

## 与现有 5 个游戏的区分

- `mining` 负责放置点击与长线累积。
- `runner` 负责高频短局与即时操作。
- `defense` 负责三路布阵、防守波次和中后期研究。
- `gem-forge` 负责熔炼、合成、升阶、稀有掉落循环。
- `drone-squad` 负责可视化射击、部件装配与强卡点突破。
- `neon-cards` 负责：
  - `拖放出牌`
  - `三路对线`
  - `短局胜负`
  - `卡组构筑`
  - `卡包 / 碎片 / 赛季 / 充值礼包` 的长期循环

它要解决的是：现有 1~5 号游戏里，还缺一个“更适合做卡组追求、碎片养成、季票与卡包付费”的品类。

## 核心玩法循环

1. 进入 `对战 Clash`
2. 选择当前章节
3. 开局拖动手牌到 3 条路中的任意一路
4. 单位自动前进、自动攻击，战术卡手动释放
5. 中局触发 1 次 `战术加压` 选择，避免频繁弹窗打断
6. 击破敌方核心或在时限内取得优势后结算
7. 获得金币、战术核心、卡片碎片、赛季经验
8. 回到 `卡组 Deck` 升卡、升星、换阵容
9. 回到 `研究 Lab` 做永久成长
10. 通过 `任务 / 赛季 / 商店 / 充值` 补足卡点并形成付费闭环

## 单局战斗节奏

- 单局时长：`60~75 秒`
- 战场结构：`3 条路`
- 初始能量：`4`
- 最大能量：`10`
- 能量恢复：`1 / 秒`
- 出牌区：`4 张手牌`
- 卡组结构：`1 队长 + 3 单位 + 1 战术`
- 中局选择：`仅 1 次`
- Boss 关：每章第 `3` 关

### 战斗内操作

- `拖牌上场`：把单位拖到任一路上场
- `点战术卡`：手动释放护盾、过载、沉默、空投等战术效果
- `压轴技能`：队长技能槽满时点一次释放

### 战斗节奏节点

- `0~10 秒`：抢前线、铺第一张前排
- `10~28 秒`：补后排与技能，建立路权
- `28 秒`：出现 1 次战术强化三选一
- `30~55 秒`：精英压线，考验卡组厚度
- `60 秒左右`：Boss 关出现指挥官 / 核心单位

## 页面结构

### 1. 对战 Clash

- 主玩法页
- 单屏必须看到：
  - 当前章节
  - 推荐战力与当前战力差
  - 3 路战场
  - 能量条
  - 队长技能按钮
  - 开始对战按钮
- 这一页不堆研究说明、长文本、赛季说明

### 2. 卡组 Deck

- 合并“卡组配置 + 卡片库存 + 碎片升级 + 卡包开箱”
- 单屏优先展示：
  - 当前上阵 5 卡
  - 当前钱包：金币 / 核心 / 芯片
  - 当前推荐补强方向
  - 可立即升级的 4~8 张卡
- 避免做太长的卡库列表，默认只显示：
  - 已上阵
  - 可升级
  - 新解锁

### 3. 研究 Lab

- 只保留 5 条永久研究线
- 不做复杂分叉树
- 每条研究都要明确告诉玩家：
  - 升级后影响什么
  - 在对战里具体体现在哪

### 4. 任务 Missions

- 只显示：
  - 可领取
  - 即将完成
  - 长期里程碑

### 5. 赛季 Season

- 免费轨 + 赞助轨
- 只做 `20` 档，不做超长滚动页

### 6. 商店 Shop

- 免费补给
- 金币补缺
- 战术核心补缺
- 卡包 / 充值礼包

## 资源体系

### 主资源

- `credits`：金币，基础主消耗
- `tactCores`：战术核心，中期主门槛
- `cipherChips`：密钥芯片，后期硬门槛
- `seasonXp`：赛季经验，只进赛季

### 非主资源

- `cardFragments`：每张卡独立碎片，不通用
- `standardCrates`：标准卡包，产出常规碎片
- `eliteCrates`：精英卡包，产出高稀有卡与大量碎片

## 资源来源 / 消耗对应关系

| 资源 | 主要来源 | 主要消耗 |
| --- | --- | --- |
| `credits` | 章节结算、任务、赛季、每日补给、充值 | 出战门票、卡牌升级、研究、商店购买 |
| `tactCores` | 章节结算、任务、赛季、每日补给、充值 | 升星、开包、后期定向补卡 |
| `cipherChips` | Boss 首通、章节 Boss、任务、赛季、充值 | 研究、觉醒、4★ 以上升星 |
| `cardFragments` | 关卡掉落、卡包、任务、赛季、充值 | 指定卡升星 |

## 卡组规则

- 上阵规则：`1 队长 + 3 单位 + 1 战术`
- 手里只轮转 `3 单位 + 1 战术`
- 队长不进手牌，作为被动与主动技能来源
- 同一张单位卡不能重复上阵
- 每张卡有：
  - 费用 `Cost`
  - 攻击 `ATK`
  - 生命 `HP`
  - 攻速 `AS`
  - 标签 `Tag`

## Boss 首通奖励建议

- 在普通关结算基础上追加：
  - `credits = 当前章节金币 * 0.7 + 160`
  - `tactCores = 当前章节核心 * 0.8 + 10`
  - `cipherChips = 1 ~ 4`
- `4-3` 首通额外送 `eliteCrates * 1`

## 出战门票

- 每天 `3` 次免费对战
- 超出免费次数后按章节收金币

| 章节段 | 单次门票 |
| --- | ---: |
| `1-1 ~ 1-3` | `700` |
| `2-1 ~ 2-3` | `1050` |
| `3-1 ~ 3-3` | `1680` |
| `4-1 ~ 4-3` | `2520` |

这样能保证：

- 金币不会只进不出
- 免费玩家每天仍然能持续推进
- 想高频刷卡包 / 任务 / 赛季的玩家会自然感受到充值提速价值

## 升级与升星数值

### 单位卡升级

- 单位卡单级金币：`70 * 1.18^(等级-1)`
- 上限：`Lv 20`

### 队长升级

- 队长单级金币：`120 * 1.20^(等级-1)`
- 上限：`Lv 15`

### 战术升级

- 战术单级金币：`95 * 1.19^(等级-1)`
- 上限：`Lv 15`

### 升星

| 星级 | 碎片 | 战术核心 | 金币 | 芯片 |
| --- | ---: | ---: | ---: | ---: |
| `1★ -> 2★` | `20` | `18` | `800` | `0` |
| `2★ -> 3★` | `50` | `42` | `1800` | `0` |
| `3★ -> 4★` | `120` | `90` | `4200` | `2` |
| `4★ -> 5★` | `260` | `180` | `9800` | `6` |

### 星级收益

- `2★`：全属性 `+10%`
- `3★`：全属性 `+22%`
- `4★`：全属性 `+38%`
- `5★`：全属性 `+60%`

这样能明确拉开“只升级”与“升星成型”的差距，让碎片与核心真正有价值。

- 金币：`baseCredits * 1.28^(当前等级)`
- 芯片：`baseChips * 1.35^(当前等级)`

| 研究 | 金币基础 | 芯片基础 |
| --- | ---: | ---: |
| `energyMatrix` | `120` | `2` |

## 卡包 / 碎片循环

### 标准卡包

- 每天 `1` 次免费
- 免费后制造成本：
  - `360 credits + 12 tactCores`
- 每日第 `5` 次后进入涨价：
  - `620 credits + 20 tactCores`

### 保底

- 稀有保底：`8` 包
- 史诗保底：`24` 包

### 作用

- 解决“碎片只靠章节太慢”的问题
- 给金币和战术核心稳定消耗口
- 给付费礼包提供显著但不唯一的追赶价值

## 任务与赛季

### 任务方向

- 对战次数
- Boss 击败次数
- 单位升到指定等级
- 指定数量卡牌达到 `3★ / 4★`
- 开启卡包次数
- 研究总等级

### 赛季奖励重点

- 免费轨：金币、战术核心、标准包
- 赞助轨：芯片、精英包、定向碎片、队长碎片

## 数值卡点设计

### 新手期

- `1-1 ~ 1-2`
- 目标：快速理解拖放出牌、技能释放、三路压线
- 体感：金币够用，不立刻卡

### 第一卡点

- `1-3`
- 需要：
  - 1 张前排升到 `Lv5`
  - 1 张主输出升到 `Lv5`
  - 第一张卡 `2★`
- 目的：让玩家第一次理解“碎片 > 单纯金币”

### 第二卡点

- `2-2`
- 需要：
  - `energyMatrix Lv3`
  - 战术卡 `Lv5`
  - 至少 1 张稀有卡进队
- 目的：让玩家感知战术核心和芯片的重要性

### 第三卡点

- `3-1 ~ 3-3`
- 需要：
  - 队长 `2★`
  - 研究 2 条主线各 `Lv5+`
  - 第一次史诗保底接近触发
- 目的：形成“免费能追，但付费能明显缩短史诗成型时间”的刺激

### 终局卡点

- `4-2 ~ 4-3`
- 需要：
  - 主力卡组至少 `2 张 4★`
  - 芯片研究成型
  - 至少 1 个史诗战术 / 史诗队长
- 目的：把充值价值聚焦到“缩短定向成型时间”

## 充值设计

### 充值闭环

- 沿用现有项目的链上订单 + `TRC20-USDT` + `txid` 校验闭环
- `gameId` 直接使用 `neon-cards`
- 奖励发放包括：
  - 即时资源
  - 卡包
  - 定向碎片
  - 永久赞助加成

### 首充价值

- 解锁赞助赛季
- 额外 `+1` 每日免费对战
- 卡包保底缩短 `10%`

### 礼包档位建议

| 档位 | 名称 | 即时奖励 | 永久收益 |
| --- | --- | --- | --- |
| `6 USDT` | 新手编组包 | `3000 credits + 120 tactCores + 8 chips + 1 eliteCrate` | `能量恢复 +3%` |
| `15 USDT` | 战术补给包 | `9000 credits + 340 tactCores + 20 chips + 2 eliteCrates` | `每日免费对战 +1` |
| `30 USDT` | 队长培养包 | `21000 credits + 780 tactCores + 48 chips + 队长碎片箱` | `队长技充能 +6%` |
| `68 USDT` | 王牌卡组包 | `48000 credits + 1800 tactCores + 120 chips + 4 eliteCrates` | `全队攻击 +8% / 生命 +8%` |
| `128 USDT` | 冠军赞助包 | `108000 credits + 4200 tactCores + 280 chips + 8 eliteCrates + 自选史诗碎片` | `章节收益 +12% / 保底缩短 +15%` |

### 充值刺激点

- 充值不只给一次性资源，还给：
  - 对战频率提升
  - 研究成型速度提升
  - 卡包史诗成型速度提升
  - 章节收益提升

这会比“单纯给一堆金币”更有长期吸引力。

## 经济健康目标

### 金币

- 单关金币产出只覆盖 `0.6 ~ 0.75` 次下一档有效升级
- 中后期金币长期被：
  - 门票
  - 卡牌升级
  - 研究
  - 卡包
  一起回收

### 战术核心

- 中期最主要门槛
- 正常体验里始终略紧，但不能断供

### 芯片

- 后期硬门槛
- 主要通过 Boss、赛季、任务和礼包拉开差距

## 落地优先级

### 第一阶段

- `Clash` 单局战斗
- `Deck` 卡组与升级
- 基础章节 1~2 章
- 任务 / 商店基础闭环

### 第二阶段

- `Lab`
- 赛季双轨
- 卡包保底
- 章节 3~4 章

### 第三阶段

- 充值验证闭环
- 赞助赛季
- 定向碎片与史诗卡追求
- 长线卡点与后期数值精修

## 一句话总结

- `Game 6 = 一个更适合做卡组追求、碎片成型、赛季付费和长期卡包循环的三路实时卡战游戏。`
- 它既和前 5 个游戏区分明显，又能复用我们已经验证过的：
  - 移动端单屏布局思路
  - 任务 / 赛季 / 商店结构
  - 充值校验闭环
  - “免费可玩、充值明显提速”的数值逻辑
