# Cipher Match 模块与数值规划

## 目标定位

- 本轮默认将 `Game 7` 定义为大厅里已预留的 `cipher-match`
- 中文名：`密码消除`
- 英文名：`Cipher Match`
- 类型定位：`6x6 赛博消除 + 章节闯关 + Boss 关卡 + 局外构筑 + 赛季付费`
- 目标体验：
  - `5 秒内` 看懂是消除玩法
  - `20 秒内` 打出第一组 4 连或技能反馈
  - `3 分钟内` 形成“再过一关 / 再升一下模块”的驱动力
  - `1~3 天内` 感受到免费可玩，但付费能明显加速卡点突破

## 为什么把它作为 Game 7

- 前 6 个游戏已经覆盖了：
  - `mining`：放置与长线资源累积
  - `runner`：高频短局操作
  - `defense`：三路布防与章节推进
  - `gem-forge`：熔炼、合成、保底循环
  - `drone-squad`：自动射击 + 机库养成
  - `neon-cards`：实时卡战 + 对局构筑
- `cipher-match` 需要补的是：
  - 更容易理解的休闲主玩法
  - 更适合做日常活跃、赛季经验和轻度长线留存
  - 更适合手机单手操作的“碎片时间”闯关品类
- 它和前 6 个游戏的关系应该是：
  - 入门成本最低
  - 节奏最稳
  - 付费点更偏向“卡点突破、补资源、买继续、追保底”

## 核心玩法循环

1. 进入 `闯关 Run`
2. 选择当前章节关卡
3. 在 `6x6` 面板中滑动交换相邻方块，凑成 `3 连` 以上消除
4. 通过消除来完成关卡目标：
   - 清除指定障碍
   - 收集密钥
   - 击破 Boss 防火墙
   - 达到指定分数
5. 连击、特殊块和主动技能共同提升输出效率
6. 结算获得金币、密钥位、密码尘、赛季经验、碎片
7. 回到 `构筑 Deck` 升级主程序、辅助模块、主动技能
8. 回到 `研究 Lab` 做永久成长
9. 通过 `任务 / 赛季 / 商店 / 充值` 补齐卡点并形成长线循环

## 单局规则

### 棋盘与手感

- 棋盘尺寸：`6x6`
- 主要输入：`滑动交换`
- 单局目标时长：`45~100 秒`
- 单局目标数量：`最多 2 个主目标`
- 每局默认步数：
  - 普通关：`18~24 步`
  - 精英关：`20~26 步`
  - Boss 关：`24~30 步`

### 基础消除规则

- `3 连`：基础消除
- `4 连`：生成直线破解器
- `5 连`：生成全色破解器
- `T / L 形`：生成范围炸弹
- 连续下落形成 `Combo` 时，为主动技能额外充能

### Boss 关规则

- 每章最后一关为 `Boss 关`
- Boss 不做复杂站桩战斗，直接表现为棋盘上的“防火墙目标”
- Boss 每 `2~3` 回合触发一次机制：
  - 上锁
  - 生成病毒块
  - 压缩步数收益
  - 强化障碍耐久
- Boss 关胜利必须通过：
  - 清空 Boss 护盾层
  - 或把 Boss 生命条打到 `0`

### 失败与继续

- 关卡失败后，可选择：
  - `直接退出`
  - `消耗金币购买 +5 步`
- 单局最多购买继续 `2 次`
- 继续价格：
  - 第 1 次：`220 credits`
  - 第 2 次：`440 credits`
- 前 `8` 个新手关卡失败不扣继续次数，避免上手挫败

## 移动端页面结构

### 1. 闯关 Run

- 这是主玩法页，单屏必须直接看到：
  - 当前章节与关卡
  - 推荐战力 / 当前战力
  - 棋盘主舞台
  - 当前步数
  - 当前目标
  - 主动技能按钮
  - 开始闯关按钮
- 顶部信息只保留最关键的 4 项：
  - 章节
  - 战力
  - 免费次数
  - 当前关卡收益重点
- 所有其他说明文字都不要堆在这一页

### 2. 构筑 Deck

- 合并：
  - 主程序选择
  - 辅助模块选择
  - 主动技能选择
  - 升级 / 升星
  - 秘钥开包
- 单屏优先展示：
  - 当前上阵 `1 主程序 + 2 模块 + 1 技能`
  - 当前金币 / 密钥位 / 密码尘
  - 当前最推荐升级项
  - 可立即升级的卡牌

### 3. 研究 Lab

- 只保留 `5` 条永久研究线
- 每条研究必须明确写清楚：
  - 升级后影响什么
  - 在局内具体体现在哪

### 4. 任务 Missions

- 只显示：
  - 可领取
  - 接近完成
  - 长期里程碑

### 5. 赛季 Season

- 免费轨 + 赞助轨
- 默认展示前后各 `2~3` 档，减少长列表疲劳

### 6. 商店 Shop

- 每日免费
- 金币追赶
- 密钥位追赶
- 密码尘追赶
- 充值礼包

## 移动端 UI 原则

- `Run` 页优先棋盘，不让顶部信息吃掉过多空间
- 非 `Run` 页尽量采用：
  - 横向卡带
  - 两列卡片
  - 图标 + 数字优先
- 每张卡片控制在：
  - 1 行标题
  - 1 行关键描述
  - 1 行消耗
  - 1 组按钮
- 避免长段说明文；复杂规则用：
  - 图标
  - 小标签
  - 悬浮提示

## 资源体系

### 主资源

- `credits`：金币，基础主消耗
- `keyBits`：密钥位，中期主门槛
- `cipherDust`：密码尘，后期硬门槛
- `seasonXp`：赛季经验，只进入赛季

### 非主资源

- `programFragments`：主程序碎片，按角色独立
- `moduleFragments`：模块碎片，按模块独立
- `skillFragments`：技能碎片，按技能独立
- `standardKeys`：标准秘钥，用于普通开包
- `eliteKeys`：精英秘钥，用于高价值开包

## Boss 首通奖励

- 在基础结算外额外追加：
  - `credits = 当前关卡金币 * 0.8 + 120`
  - `keyBits = 当前关卡密钥位 * 0.9 + 6`
  - `cipherDust = 1 ~ 4`
- `4-6` 首通额外给：
  - `eliteKeys +1`

## 出战门票

- 教学前 `8` 关，不消耗每日次数
- 每天 `6` 次免费闯关
- 免费次数用完后，继续挑战消耗金币

| 章节 | 单次门票 |
| --- | ---: |
| `1章` | `180 credits` |
| `2章` | `320 credits` |
| `3章` | `540 credits` |
| `4章` | `880 credits` |

这样可以保证：

- 免费玩家每天都能推进
- 金币不会只进不出
- 想高频刷碎片、任务、赛季的玩家会自然感觉到金币压力

## 开包与碎片循环

### 标准秘钥

- 每日免费：`1 把`
- 免费后单次购买：`220 credits + 12 keyBits`

### 精英秘钥

- 主要来自：
  - Boss 首通
  - 赛季节点
  - 高价值礼包

### 保底

- `10` 把标准秘钥内至少出一次高价值碎片包
- `12` 把精英秘钥内至少出一次稀有主程序 / 技能碎片大包

### 开包目的

- 解决“碎片只靠关卡掉落太慢”的问题
- 为金币和密钥位提供稳定消耗口
- 为付费礼包提供“明显加速，但不是唯一来源”的价值

## 新手到骨灰玩家的数值线

### 新手期（0~40 分钟）

- 目标：看懂消除、知道 4 连 / 5 连、学会点技能
- 资源感受：金币够用，密钥位不缺，密码尘先不露出压力
- 体验关键词：爽、快、清楚

### 成型期（40 分钟 ~ 1 天）

- 目标：形成一套主程序 + 2 模块 + 1 技能
- 资源感受：金币开始偏紧，密钥位开始成为门槛
- 体验关键词：再升一级就能过

### 卡点期（1~3 天）

- 目标：推进 `2章后半 ~ 3章前半`
- 资源感受：
  - 金币持续紧张
  - 密钥位明显不足
  - 密码尘第一次成为硬门槛
- 体验关键词：免费能磨，但充值会明显快很多

### 骨灰期（3~7 天）

- 目标：冲 `4章`，追精英秘钥保底与赛季赞助收益
- 资源感受：
  - 主靠密码尘和精英秘钥卡强度
  - 继续次数、局内道具、Boss 奖励增幅都开始有价值
- 体验关键词：高效率冲关、保底追赶、赛季收益拉满

## 产出 / 消耗比例原则

- 单次普通关金币产出，只覆盖下一次“有效升级”的 `45% ~ 60%`
- 单次 Boss 关密钥位产出，只覆盖一个中期模块升级的 `50%` 左右
- 密码尘必须保持稀缺：
  - 免费玩家每 `6~10` 个关键节点才能稳定点 1 次高价值研究
  - 中付费用户能把这一节奏压缩到 `2~4` 个节点
- 继续购买与局内道具必须成为有效金币回收口
- 保证整体体验不是“产出大于消耗”，否则很快失去充值冲动

## 最终设计原则

- `Game 7` 必须比 `Game 6` 更容易看懂
- 主玩法页必须一进来就看到棋盘，不要被头部信息压掉

  - 让玩家知道下一步该补什么
  - 让充值后的提升足够直接、足够明确
