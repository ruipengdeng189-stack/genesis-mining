# Iron Frontier 关卡资源消耗与推进路线

## 1. 说明

本表用于把 `iron-frontier` 的成长结论进一步细化到“逐关目标 / 资源补齐 / 推进路径”。

- 这里的资源以未来运行时配置为准
- `增量消耗`：相对上一个节点新增需要补齐的资源
- `累计消耗`：从新号默认状态一路补到当前节点的总投入
- `免费 / 小付费 / 中付费` 仅用于内部调优，不直接作为用户前台文案

记法：

- `SC = Scrap`
- `FC = Fuel Cells`
- `CC = Core Chips`
- `RD = Relay Data`

## 3. 路线拆分

### `1-1 ~ 1-6`

| 类型 | 通过路线 |
| --- | --- |
| 免费 | 先补 `主炮 Lv2 → 装甲车 Lv2 → 主炮 Lv3`，再把 `车头 Lv3 + 支援车 Lv2 + 终极 Lv2` 补齐 |
| 小付费 | `starter` 后，首章能同步补 `车头 + 主炮 + 支援`，Boss 关容错明显提高 |
| 中付费 | 不建议在首章做过重付费，首日重点仍是理解按钮、节奏和模块分工 |

### `2-1 ~ 2-6`

| 类型 | 通过路线 |
| --- | --- |
| 免费 | 优先把主炮拉到 `Lv5`，再补 `Fire Director / Salvage`，保证输出和收益同步 |
| 小付费 | `starter + convoy` 后，中期成长会明显顺滑，适合同时推进主炮与研究 |
| 中付费 | 可以提前把乘员同步到 `Lv3`，减少“模块等级到了但技能循环不顺”的断层 |

### `3-1 ~ 3-6`

| 类型 | 通过路线 |
| --- | --- |
| 免费 | 先补 `支援车 Lv4 + 装甲车 Lv4`，再推 `终极 Lv4` 与乘员 `Lv3`，优先保证完整编组 |
| 小付费 | `starter + convoy + captain` 后，`3-3` 开始就能形成完整战斗循环 |
| 中付费 | 适合提前推 `Fire Director 4` 与 `Repair 3`，把精英波和 Boss 波打得更稳 |

### `4-1 ~ 4-6`

| 类型 | 通过路线 |
| --- | --- |
| 免费 | 进入长期目标区，重点是同步补齐主炮、装甲、研究，不建议只拉单点输出 |
| 小付费 | 前三档礼包 + 稳定活跃可推进到 `4-3 ~ 4-4`，后续主要拼时间与回收效率 |
| 中付费 | `arsenal + frontier` 负责终盘追平，但终盘表现仍应主要取决于整备质量与技能时机 |

## 6. 未来反推建议

下一步如果进入实现，建议把本表反推回配置时同步落地：

1. `stages[i].goalTags`
2. `stages[i].goalCost`
3. `stages[i].totalCost`
4. `paymentOffers[i].targetWindow`
5. `runSummary` 页签中的“近期补齐建议”

这样可以保证：

- 关卡目标有明确成长映射
- 每个礼包对应的收益窗口清晰
- Run 页的推荐信息不是泛提示，而是来自真实数值目标
