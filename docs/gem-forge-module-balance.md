# Gem Forge 模块与数值整理

## 目标定位

- 假设当前要启动的第 4 个游戏是 `gem-forge`（大厅里第一个待开放的新项目）。
- 玩法定位沿用第 2 个游戏 `runner` 和第 3 个游戏 `defense` 的结构优势：
  - 1 个主玩法页，负责即时反馈与短线爽点。
  - 1 个部署/合同页，负责“当前卡点”和“下一步去哪里”。
  - 1 个装配页，负责构筑差异与长期成长。
  - 1 个研究/工坊页，负责永久数值成长。
  - 任务、赛季、商店三页负责资源回流、长期目标与付费收口。
- 核心体验不是“纯摆放”，而是“熔炼 - 合成 - 升阶 - 觉醒 - 卡点突破”。

## 页面结构

### 1. 熔炉

- 主玩法页，对应 `runner` 的 `run` 页与 `defense` 的 `defend` 页。
- 单屏必须能看懂 5 件事：
  - 当前合同
  - 熔炉热量
  - 本轮高阶保底
  - 当前主 build 的 3 个符印
  - 立即熔炼 / 批量熔炼按钮
- 主反馈是：
  - 熔出宝石
  - 合成成功
  - 升阶成功
  - 保底触发
  - 觉醒材料进度

### 2. 合同

- 对应 `defense` 的 `prep` 页。
- 用来选择当前推进的合同章节、查看推荐熔炉战力、掉落偏向、下一档目标。
- 必须明确回答：
  - 当前在哪一档
  - 距离下一档差多少
  - 最该补的是热量、稀有率、碎片，还是催化剂

### 3. 符印

- 对应 `runner` 的 `loadout` 与 `defense` 的 `loadout`。
- 采用 3 槽构筑：
  - 主熔槽：主产出
  - 共鸣槽：连锁增益
  - 余烬槽：经济回流
- 资源规则要清楚：
  - 每个符印使用自己的碎片升级
  - 顶部“总碎片”只是总库存，不是通用消耗

### 4. 工坊

- 对应 `defense` 的 `research` 页。
- 提供永久成长，不做复杂分支树，直接保留 5 条可理解的主线：
  - 热量上限
  - 热量恢复
  - 稀有率强化
  - 熔尘回收
  - 催化剂提炼

### 5. 任务

- 对应 `runner` / `defense` 的 `missions`。
- 只保留“当前能领、离完成最近、长期里程碑”三种信息层级。

### 6. 赛季

- 对应 `runner` / `defense` 的 `season`。
- 免费轨 + 赞助轨双轨结构沿用。
- 赛季经验主要来源：
  - 熔炼次数
  - 合同突破
  - 合成高阶宝石
  - 觉醒成功

### 7. 商店

- 对应 `runner` / `defense` 的 `shop`。
- 商店只保留 4 类：
  - 每日免费
  - 金币箱
  - 熔尘箱
  - 充值礼包

## 核心资源

### 软货币

- 金币：所有基础升级的主消耗。
- 熔尘：升阶与后期构筑的中阶消耗。
- 催化剂：高阶升阶、觉醒、终局保底的硬门槛资源。
- 赛季经验：赛季结算资源，不参与核心成长支付。

### 构筑资源

- 符印碎片：每个符印独立碎片，不通用。
- 宝石库存：用于合成、分解、觉醒。

### 付费资源

- 不单独再发“钻石”。
- 充值直接给：
  - 金币
  - 熔尘
  - 催化剂
  - 符印碎片
  - 赞助等级提升
- 这样和第 2、3 个游戏一致，避免多货币让人看不懂。

## 核心玩法循环

### 早期循环

- 熔炼拿低阶宝石
- 3 合 1 提升宝石阶级
- 用金币升级工坊前 2 条线
- 解锁第 2、3 个符印槽

### 中期循环

- 推合同卡点
- 通过符印构筑去拆掉“当前差值”
- 金币开始紧缺
- 熔尘开始成为中期硬门槛

### 后期循环

- T4/T5 宝石升阶
- 催化剂成为主门槛
- 觉醒和赞助轨开始显著拉开效率
- 金币不再只是富余，而是被高阶升阶、洗练、商店回收掉

## 成长曲线

### 档位划分

- 新手档：合同 1-1 到 1-3
- 成型档：合同 2-1 到 2-3
- 卡点档：合同 3-1 到 3-2
- 终局档：合同 3-3 以后

### 体感目标

- 前 15 分钟：快速解锁 3 槽符印和 T2 合成
- 前 40 分钟：进入第一次“金币不够”的感知
- 前 90 分钟：进入第一次“熔尘不够”的感知
- 前 1-2 天：进入第一次“催化剂不够，充值会明显提速”的感知

## 资源产出与消耗比

### 金币

- 不能再做成“只会溢出”的资源。
- 目标是：
  - 新手期：基础够用
  - 中期：持续紧张
  - 后期：高阶升阶和商店一起吃掉冗余金币

建议比例：

- 合同单次金币产出：只覆盖 0.55 到 0.7 次下一档主升级
- 单次“批量熔炼”金币回收：只能回一小部分，不做正收益
- 中后期金币箱价格成长必须明显高于常规金币产出成长

### 熔尘

- 中期开始变成第二卡点。
- 目标是：
  - 玩家能稳定产出，但想追高阶必须主动攒或充值补

建议比例：

- T2 -> T3：轻度需求
- T3 -> T4：明显卡点
- T4 -> T5：必须规划

### 催化剂

- 只在关键节点发放。
- 目标是：
  - 免费玩家能推进，但速度明显慢
  - 充值会直接缩短“攒催化剂”的等待

## 付费刺激设计

### 充值应该解决什么问题

- 不是“多一点金币”，而是明确解决 3 类卡点：
  - 当前合同差一截战力
  - 高阶升阶缺熔尘
  - 觉醒/终局冲档缺催化剂

### 付费后必须有体感

- 第一笔：立刻开赞助轨，提升热量上限和稀有率
- 第二档：明显减少中期缺熔尘
- 第三档：直接帮助跨过 2-3 / 3-1 这类合同墙
- 高档：直接加速 T4/T5 与觉醒

### 累充里程碑

- 只做 4 档，避免信息疲劳。
- 每档都要同时给：
  - 即时资源
  - 永久增益
  - 下一步更高效率

## 推荐数值结构

### 合同推荐战力

| 合同 | 推荐战力 |
| --- | ---: |
| 1-1 | 180 |
| 1-2 | 320 |
| 1-3 | 540 |
| 2-1 | 860 |
| 2-2 | 1260 |
| 2-3 | 1780 |
| 3-1 | 2440 |
| 3-2 | 3260 |
| 3-3 | 4320 |

### 工坊升级费用目标

- 热量上限：低开高走，金币主消耗
- 热量恢复：略低于热量上限，保证手感
- 稀有率强化：金币 + 熔尘混合
- 熔尘回收：金币 + 催化剂少量点缀
- 催化剂提炼：中后期才显著开启

### 符印强度分层

- 基础符印：入门即可解锁
- 进阶符印：中期解锁，拆合同墙
- 终局符印：后期/赞助/高阶商店主供给

## 与第 2、3 个游戏的对齐点

### 对齐 `runner`

- 用“主玩法 + 装配 + 任务 + 赛季 + 商店”的轻量框架
- 充值直接提升体验，不做抽象货币解释

### 对齐 `defense`

- 增加“合同”和“工坊”两个更清晰的成长页
- 用“当前差多少、下一步补什么”的路线提示降低理解成本
- 用合同推荐战力，明确卡点与数值线

## 建议实现顺序

### 第 1 期

- 熔炉主页面
- 合同页面
- 符印页面
- 基础工坊

### 第 2 期

- 任务
- 赛季
- 基础商店
- 基础充值弹窗

### 第 3 期

- 觉醒
- 赞助轨
- 累充里程碑
- 终局 T4/T5 循环
