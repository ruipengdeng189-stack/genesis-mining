# Orbital Fall 日循环经济模型

## 1. 本轮目的

这份文档用于把 `Missions / Season / Shop` 三块的资源产出，整理成真正可落到运行时的“日循环回收模型”。

本轮处理的核心点有两个：

1. `Missions` 从一次性前置奖励，改成真正的 `每日任务`
2. 按 `新手 / 中期 / 后期` 与 `白嫖 / 小氪 / 中氪`，定义对应的日循环路线

---

## 2. 任务系统修正

在这轮之前，`missions` 的完成进度使用的是累计总统计：

- `runs`
- `survivalSeconds`
- `eliteKills`
- `stageClears`
- `bossKills`

这会导致任务更像“一次性成就”，而不是日活系统。

现在改为：

- 任务按 `dayKey` 每日刷新
- 每天记录一份 `missionDailyBaseStats`
- 当日任务进度 = `当前总统计 - 当日基准统计`

这样 `Missions` 才能真正作为：

- 每日活跃承接
- 日循环资源补充
- 与 `Season / Shop` 联动的经济来源

## 3. 日循环分层

### 新手期 `1-1 ~ 1-6`

| 路线 | 推荐关卡序列 | 说明 |
| --- | --- | --- |
| 白嫖 | `1-4 → 1-5 → 1-6 → 1-6` | 4 局吃满前期任务与日补给，回头补 `1-6` 前后的成长缺口 |
| 小氪 | `1-5 → 1-6 → 1-6 → 2-1 → 2-1` | 通过 `starter` 的额外加成局，把首章过渡直接拉到 `2-1` 附近 |
| 中氪 | `1-6 → 1-6 → 2-1 → 2-2 → 2-2` | 更早开始中期资源循环，但主投入仍应是武器、机体和赛季推进 |

### 中期 `2-1 ~ 3-3`

| 路线 | 推荐关卡序列 | 说明 |
| --- | --- | --- |
| 白嫖 | `2-3 → 2-4 → 2-5 → 2-6` | 4 局稳定回收，优先补 `武器 / 合金压铸 / 大招` |
| 小氪 | `2-4 → 2-5 → 2-6 → 2-6 → 3-1` | 多打一局把合金和信号压力一起摊平，更容易连推到 `3-x` |
| 中氪 | `2-5 → 2-6 → 2-6 → 3-2 → 3-3` | 双线赛季和更高资源回收并行，构筑成型明显提前 |

### 后期 `3-4 ~ 4-6`

| 路线 | 推荐关卡序列 | 说明 |
| --- | --- | --- |
| 白嫖 | `3-4 → 3-5 → 3-6 → 4-1` | 稳定 4 局为主，优先保证核心研究和无人机同步 |
| 小氪 | `3-5 → 3-6 → 3-6 → 4-1 → 4-2` | 更适合冲 `4-2 ~ 4-4`，把高压关收益吃满 |
| 中氪 | `4-2 → 4-3 → 4-4 → 4-5 → 4-6 → 4-6` | 后期主打高收益章节和双线赛季，终盘缺口显著缩短 |

## 4. 三个页签的职责

### `Missions`

现在应该承接：

- 当日活跃目标
- 当日回收总量
- 今日推荐日循环

运行时已落地：

- `今日回收`
- `几局 / 几任务 / 几个加成局`
- `当日预计总回收`

### `Season`

现在应该承接：

- 赛季经验的日速率
- 免费线的下一档进度
- 高级线的下一档进度

运行时已落地：

- `约 +X XP/日`
- `免费下一档还差多少`
- `高级下一档还差多少 / 是否未开启`

### `Shop`

现在应该承接：

- 每日补给的固定收益
- 软货币补给的优先级
- 根据下一关键节点，提醒当前更缺哪种资源

运行时已落地：

- `补给节奏`
- `日补给收益`
- `优先看哪几个软货币补给`

## 5. 当前实现策略

本轮没有把“每日回收表”写死成静态数字，而是让运行时动态估算：

1. 根据当前 `选中关卡`
2. 根据当前 `已购礼包`
3. 根据当前 `研究加成 / 永久收益`
4. 按对应的 `dailyRouteModels`

动态算出：

- 关卡回收
- 任务回收
- 日补给回收
- 赛季 XP 日速率

这样好处是：

- 文档和运行时不容易脱节
- 后面只要改章节奖励或研究倍率，日循环卡会自动跟着变化

---

## 6. 与上一轮资源表的关系

上一轮 `docs/orbital-fall-stage-resource-sim.md` 解决的是：

- 下一个关键节点需要补什么
- 补齐要花多少资源

这轮补上的则是：

- 每天该怎么跑
- 这些资源每天从哪里回
- 回收速度和下一关键节点如何对应

两者组合后，`game8` 的成长线会更完整：

1. `Run` 页告诉你“下一档该补什么”
2. `Missions / Season / Shop` 告诉你“今天怎么回这些资源”

## 7. 下一轮建议

如果继续细化，建议优先做：

1. 把 `每日回收` 再补成 `预计几天补齐下一关键点`
2. 把 `Season` 的日 XP 速率，反推成 `免费线 / 高级线` 的节点领取节奏
3. 把 `Shop` 的软货币补给，做成更明确的 `当前优先 1 / 2 / 3`
