# Combat SFX Playtest Checklist

更新时间：2026-05-08

## 目标

这份清单用于对 `game1~8` 做一轮逐游戏实机试听，重点验证：

- 战斗开始是否有明确开场反馈
- 普攻 / 命中 / 护盾 / 受击是否能被用户区分
- 技能就绪 / 技能释放 / Boss 出场是否足够醒目
- 高频音效是否刺耳、疲劳，低频反馈是否过闷
- 音效开关是否生效，且不会影响核心交互

## 通用验收标准

- 进入战斗后，玩家应在 `1~3` 秒内听到至少一个“这是战斗状态”的明确反馈
- 高频重复音效不能刺耳，连续游玩 `3~5` 分钟不应明显疲劳
- 高价值事件优先级必须清晰：`Boss/技能/胜负` > `命中/消除` > `普通射击/掉落`
- 左右位置明显的玩法，音效最好有一定空间感，不应全部像从屏幕正中发出
- 同类事件连续触发时不能糊成一团，节流后仍要能听出节奏
- `SFX ON/OFF` 开关切换后应立即生效，并在刷新后保持状态

## 建议测试环境

- 桌面 Chrome
- 安卓 Chrome
- iPhone Safari
- 外放扬声器 + 耳机各一轮

## Game1 `mining`

**入口**

- 进入 `games/mining/`

**必听动作**

- 首次点击矿核，确认点击采矿反馈是否即时
- 连续点击 `10` 次，确认高频反馈是否刺耳
- 掉落普通宝石 / 高阶宝石时，确认奖励音是否有层级差
- 触发强化、连击、升档、爆发收益时，确认音效明显增强
- 持续游玩 `60` 秒，确认背景音乐与效果音不会互相盖住

**通过标准**

- 点击、掉落、升级、稀有收益四类音能明显区分
- 音乐持续播放时，核心收益音仍然能听见

**重点关注**

- 当前是独立音频系统，重点查“音乐盖住收益反馈”与“高频点击疲劳”

## Game2 `runner`

**入口**

- 进入 `games/runner/`

**必听动作**

- 点击开跑，确认开局音足够明确
- 连续执行 `jump / slide / jump / slide`
- 拾取金币、能量球，确认奖励音和跑动音不会混
- 释放技能，确认技能音明显高于普通动作
- 故意撞障碍，确认受击音足够刺痛但不炸耳
- 完成一局，试听胜利 / 结算奖励反馈

**通过标准**

- `jump`、`slide`、`skill`、`hit` 一耳能分出来
- 技能反馈必须强于普通移动，不然用户容易误判是否成功释放

**本轮微调**

- 强化了开跑、技能、受击三类反馈，便于在高速节奏中听清状态切换

---

## Game3 `gem-forge`

**入口**

- 进入 `games/gem-forge/`

**必听动作**

- 开始锻造一次
- 获得普通锻造结果与高价值结果各一次
- 触发回收、合成、觉醒
- 若出现高稀有藏品 / relic，确认庆祝感是否明显

**通过标准**

- `forgeStart` 与 `forgeResult` 必须分层
- `relic` 应明显比普通结果更“值钱”

**重点关注**

- 虽然不是正面战斗游戏，但资源结果页仍然需要强反馈，避免“做了事却像没发生”

---

## Game4 `cipher-match`

**入口**

- 进入 `games/cipher-match/`，点“开打”

**必听动作**

- 首次选中格子，再取消一次
- 做一次无效交换
- 做一次普通 `3-match`
- 做一次 `4+` 或连锁 `cascade`
- 推进一次目标，确认目标推进音是否能听出
- 触发掉落、Boss 压力提示
- 释放技能
- 失败后购买步数 / 继续，再试听支付后奖励触发

**通过标准**

- `select / noMatch / swap / match / cascade / goal / skill` 七类反馈必须分明
- 连锁音必须比普通消除更爽，不然无法放大“好操作”的奖励感

**重点关注**

- 棋盘操作频率高，注意高频音是否会显得毛躁
- 掉落音只能做辅助，不能抢过消除与目标推进

## Game5 `defense`

**入口**

- 进入 `games/defense/`，开始防守

**必听动作**

- 开局开始战斗
- 观察炮塔持续攻击 `10` 秒
- 等待新 wave，到最终 wave / Boss wave 再听一轮
- 触发护盾吸收、核心受击
- 技能充满后试听 Ready 音，再释放技能
- 选择一轮战中升级
- 击杀普通怪、精英、Boss
- 试听胜利 / 失败结算

**通过标准**

- 高压状态下仍能分辨：`wave`、`bossWarning`、`skillReady`、`core hit`
- 技能释放后必须让用户明确知道“已经放出去了”

**重点关注**

- 三路线信息密度高，最容易出现音效堆叠，需要重点听是否糊

---

## Game6 `drone-squad`

**入口**

- 进入 `games/drone-squad/`，开始 sortie

**必听动作**

- 开局自动开火，连续听 `5~8` 秒
- 命中普通敌人、命中 Boss
- 精英出场、Boss 到场
- 吃到充能球，确认资源回收音足够清楚
- 技能充满，确认 Ready 音
- 释放大招
- 试玩护盾受击与掉血受击各一次
- 击杀普通敌人与 Boss

**通过标准**

- 高频子弹声不能刺耳，但命中要能听见
- `charge ready` 必须能拉住注意力，引导玩家及时放技能
- 护盾受击与裸血受击必须明显区分

**本轮微调**

- 新增了子弹命中音、充能拾取音、技能满充能音，并强化了 Boss 命中差异

---

## Game7 `neon-cards`

**入口**

- 进入 `games/neon-cards/`，开始 clash

**必听动作**

- 选卡一次、部署单位一次
- 释放战术卡一次
- 领袖技能充满，确认 Ready 音
- 释放领袖技能
- 让双方单位互殴，确认普通命中节奏
- 让我方打敌方核心一次，让敌方打我方核心一次
- 听普通敌人击破与 Boss 击破

**通过标准**

- `deploy / tactic / leader ready / leader cast / core hit / boss down` 六类音能明确拉开
- 核心受击必须比普通单位互殴更重，不然战况判断会失焦

**本轮微调**

- 新增了领袖技能 Ready、核心受击、敌军/Boss 倒地等关键反馈

---

## Game8 `orbital-fall`

**入口**

- 进入 `games/orbital-fall/`，开始 run

**必听动作**

- 开局移动并自动开火
- 命中杂兵、被敌弹命中、护盾吸收伤害
- 精英刷出、Boss 到场
- 大招充满，确认 Ready 音
- 释放大招
- 击杀普通敌人 / 精英 / Boss
- 选择一轮局内强化
- 胜利 / 失败各试听一轮

**通过标准**

- `shoot` 可以退居背景，但 `hit / shieldHit / skillReady / ultimate / bossDown` 必须前景化
- 大招充满到释放这一整段，应有完整的“蓄势 → 爆发”听觉体验

**本轮微调**

- 新增了真实生效的大招满充能提醒，并把击杀回能 / 续关回满都接进同一套音效状态

## 记录模板

建议每个游戏至少记录以下 5 项：

- 听不清的事件
- 过响 / 过尖的事件
- 手感最好的一处反馈
- 与画面不一致的一处反馈
- 需要继续增强的技能 / 特效

## 本轮结论建议

- 先重点实测 `defense / drone-squad / neon-cards / orbital-fall`，这四个游戏最吃战斗反馈层级
- `cipher-match` 重点听“普通消除 vs 连锁消除 vs 目标推进”是否足够分层
- `mining / runner / gem-forge` 当前更适合查“长时间游玩疲劳感”而不是“是否有音”
