# Orbital Fall 关卡资源消耗与推进路线

## 1. 说明

本表用于把 `orbital-fall` 的成长结论继续细化到“阶段目标 / 资源消耗 / 推进路线”。

- 所有资源消耗以 `games/orbital-fall/orbital-fall.config.js` 为准
- `增量消耗`：相对上一个关键节点，新增需要补齐的资源
- `累计消耗`：从新号默认状态一路补到当前节点，总计需要投入的资源
- 这里的“白嫖 / 小氪 / 中氪”仅用于内部调优，不直接作为用户前台文案

## 3. 路线拆分

### `1-1 ~ 1-6`

| 类型 | 通过路线 |
| --- | --- |
| 白嫖 | 用初始资源先补 `双武 Lv2`，打完 `1-1 ~ 1-3` 后补 `第二武器 Lv3 + 推进网格 1`，到 `1-6` 前补 `机体 Lv3 + 核心反应堆 1` |
| 小氪 | `starter` 后，直接把 `双武 Lv3 + 机体 Lv3` 补齐，首个 Boss 容错明显提高 |
| 中氪 | 不建议在首章过早重氪，首日体验重点仍应放在理解走位、升级三选一和大招节奏 |

### `2-1 ~ 2-3`

| 类型 | 通过路线 |
| --- | --- |
| 白嫖 | 优先把主力双武拉到 `Lv5`，再补 `推进网格 3 + 合金压铸 2`，必要时把大招补到 `Lv2` |
| 小氪 | `starter + accelerator` 后，中期资源循环会顺很多，适合同时推进武器和研究 |
| 中氪 | 可以提前把赛季高级线收益吃满，让 `2-3` 到 `3-1` 之间的研究压力显著下降 |

### `3-1 ~ 3-3`

| 类型 | 通过路线 |
| --- | --- |
| 白嫖 | 先完成 `双武 Lv6`，再补 `大招 Lv3 + 精英协议 2`，保证精英和 Boss 关都能稳定处理 |
| 小氪 | `starter + accelerator + rush` 后，构筑成型明显提前，`3-3` 的压力主要回到操作与路线选择 |
| 中氪 | 赛季奖励、任务和礼包联动后，可以把研究同步往上提，减少单一模块被迫超前的情况 |

### `4-1 ~ 4-6`

| 类型 | 通过路线 |
| --- | --- |
| 白嫖 | 进入长期目标区，重点是同步补 `双武 / 无人机 / 核心研究`，不建议只拉单点战力 |
| 小氪 | 前三档礼包 + 稳定活跃可推进到 `4-2 ~ 4-4`，后续主要拼时间与资源转换效率 |
| 中氪 | `starter + accelerator + rush + sovereign` 是后期最顺组合，`nexus` 负责终盘多线追平，不应替代基础操作 |

## 4. 运行时落地说明

本轮已经把以下内容反推回运行时：

1. `Run` 页当前建议卡，新增关键节点的：
   - 近期目标标签
   - 近期补齐成本
2. `3-3` 节点推荐焦点修正为 `tesla-web / ultimateLv3 / elite-protocol-2`
   - 原因：`singularity-core` 解锁点在 `3-4`，不能用于 `3-3` 前的目标建议
3. 配置中为关键节点增加：
   - `goalTags`
   - `goalCost`
   - `totalCost`

## 5. 后续建议

如果继续细化下一轮，优先级建议是：

1. 把 `4-6` 的最终构筑再拆成“免费终盘版 / 中付费终盘版”两档
2. 将 `Missions / Season / Shop` 的资源产出，反推到这张表里做“每日活跃回收期”模型
3. 对 `battle reward` 再做一次模拟，验证 `4-x` 的资源回收速度是否足够支撑后期研究线
