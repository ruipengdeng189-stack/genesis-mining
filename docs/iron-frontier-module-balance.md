# Iron Frontier 模块与玩法设计

## 1. 产品定位

- `Game 9` 暂定代号：`iron-frontier`
- 中文名：`铁轨远征`
- 英文名：`Iron Frontier`
- 类型：`列车生存经营 + 自动战斗 + 路线事件 + 局外成长 + 赛季 / 商店`
- 核心目标：补足前 8 个游戏中“中轻度经营决策、资源调度、单屏高密度 APP 化整备体验”的空位

### 它和前面 8 个游戏的关系

- `mining` 负责长线主经济循环
- `runner` 负责高频短局刺激
- `gem-forge` 负责合成、稀有掉落与工坊成长
- `defense` 负责章节塔防推进
- `drone-squad` 负责射击编队与部件成长
- `neon-cards` 负责轻策略卡牌对战
- `cipher-match` 负责休闲留存与日常消耗
- `orbital-fall` 负责强战斗主场、单手高反馈生存射击
- `iron-frontier` 负责提供：`列车模块成长 + 路线事件选择 + 战斗与整备双节奏 + 更强单屏经营感`

## 2. 题材与世界观方向

- 背景为 `废土轨道网`：主城与补给站被荒野切割，玩家驾驶列车穿越危险线路，回收资源、护送补给、突破封锁
- 视觉关键词：
  - `钢铁列车`
  - `废土黄沙`
  - `红色警示灯`
  - `车厢模块`
  - `轨道前线`
- 题材好处：
  - 很适合做 `模块化成长`
  - 很适合做 `路线节点 / 站点事件`
  - 很适合做 `局内资源选择 + 局外经营补强`
  - 与 `game8` 的纯操作射击区分足够明显

## 3. 核心体验目标

- `5 秒内` 让玩家看懂：这是一个“列车自动推进、主炮自动开火、玩家负责技能与整备决策”的游戏
- `30 秒内` 让玩家完成第一次主动操作：`护盾`、`修复` 或 `超载火力`
- `90 秒内` 让玩家遇到第一次 `路线事件 / 临时强化选择`
- `3 分钟内` 形成“打一站 → 领资源 → 补整备 → 再出发”的循环
- `1~3 天内` 让免费玩家稳定推进首章与次章
- `7 天内` 让活跃玩家组出第一套成型列车构筑

## 4. 目标用户与节奏定位

- 面向：
  - 喜欢“轻经营 + 战斗表现”的用户
  - 不一定喜欢高强度走位，但愿意做成长决策的用户
  - 接受短局反复推进的移动端用户
- 单局时长目标：
  - 普通关：`100~140 秒`
  - 精英关：`140~180 秒`
  - Boss 关：`180~240 秒`
- 单日推荐节奏：
  - `4~8 局` 有效推进
  - `1~2 次` 整备页批量升级
  - `1 次` 领取任务、赛季与免费商店

## 5. 核心玩法循环

1. 在 `Run` 页选择章节、关卡与路线
2. 确认本次出战编组：`车头 + 主炮车 + 装甲车 + 支援车 + 3 名乘员`
3. 进入独立战斗场景，列车自动前进，主炮自动攻击
4. 玩家通过点击技能完成：
   - `护盾开启`
   - `紧急修复`
   - `火力超载`
   - `终极技能`
5. 每一小段战斗后触发：
   - `三选一局内强化`
   - `站点事件`
   - `补给选择`
6. 结算获得：
   - `Scrap`
   - `Fuel Cells`
   - `Core Chips`
   - `Relay Data`
   - `Season XP`
7. 回到局外：
   - `Train` 升级列车模块
   - `Crew` 升级乘员与岗位
   - `Workshop` 升级永久研究
8. 再通过 `Missions / Season / Shop / Payment` 补足成长后继续推进

## 6. 为什么 battle 页必须独立

`Iron Frontier` 的核心不是“在闯关页里塞一个小战斗窗”，而是让战斗成为单独场景，让列车推进、敌潮压迫、技能节奏本身成为主体验。

### 6.1 进入战斗前

- `Run` 页只负责：
  - 当前章节与站点
  - 推荐战力
  - 当前编组
  - 开打入口
- 不负责承载：
  - 研究树
  - 商店推销
  - 赛季长文案
  - 长段玩法解释

### 6.2 战斗进行时

- 战斗页默认隐藏大厅信息
- HUD 只保留：
  - 顶部：`车体耐久 / 护盾 / 热量 / 距离进度`
  - 中部：`短提示 / 路线事件 / 强化三选一 / Boss 预警`
  - 底部：`3 个常规技能 + 1 个终极技能 + 暂停`
- 战斗中不展示长段说明，不塞复杂商城入口

### 6.3 暂停层

- 只允许：
  - `继续`
  - `退出并结算`
  - `查看本局强化`
- 不要在暂停页重复堆叠：
  - 装备升级
  - 研究树
  - 支付弹窗

## 7. 局内核心机制

## 7.1 自动推进

- 列车默认自动前进
- 主炮自动攻击最近目标
- 支援车按冷却触发被动效果
- 玩家不做持续走位，而是专注于时机判断与技能按钮

## 7.2 局内四条即时状态

- `车体耐久`：核心生命值，归零则失败
- `护盾值`：优先承受伤害，可由装甲车与技能恢复
- `热量`：高火力技能会抬高热量，过热时输出衰减
- `推进进度`：代表本局推进距离，也是 Boss 与站点事件触发轴

## 7.3 局内主动技能设计

### 常规技能 1：`Overdrive`

- 作用：短时间提高主炮攻速与伤害
- 表现：主炮光效增强、枪口连发、火花特效
- 用途：用于清怪密集波次

### 常规技能 2：`Barrier`

- 作用：立即恢复护盾并短暂减伤
- 表现：列车外圈护罩亮起、格挡闪光
- 用途：应对精英突刺和 Boss 爆发

### 常规技能 3：`Repair`

- 作用：回复车体耐久并清除部分过热
- 表现：修理臂伸出、焊接火花、耐久数字回升
- 用途：延长容错，兼顾节奏恢复

### 终极技能：`Rail Burst`

- 作用：贯穿整条轨道的高伤害轰击
- 表现：整屏蓄能、轨道高光、贯穿爆炸
- 用途：Boss 破段、精英波清场、危急反打

## 7.4 局内三选一强化池

- 每局至少出现 `3~4 次`
- 前两次强化优先偏稳定收益：
  - `火力 +12%`
  - `护盾恢复 +18%`
  - `过热恢复 +20%`
  - `回收掉落 +15%`
- 后续强化逐渐开放构筑向收益：
  - `超载期间追加副炮`
  - `护盾破裂后自动反冲`
  - `修复同时恢复终极充能`
  - `Boss 额外易伤`
  - `事件奖励提高`

## 7.5 路线事件

- 关卡中间插入 `1~2 次`
- 只给 `2 选 1`，不做长篇阅读
- 示例：
  - `废弃站台`：拿资源 / 赶路
  - `黑市车队`：买材料 / 拿免费基础补给
  - `信号残片`：拿短期火力 / 拿长期研究材料
  - `危险岔路`：高风险高收益 / 稳定推进

## 8. 页签职责拆分

## 8.1 `Run`

- 只放：
  - 章节与关卡
  - 推荐战力
  - 当前战力
  - 路线摘要
  - 当前列车编组
  - `开打` 按钮
- 不放：
  - 完整研究树
  - 详细付费说明
  - 大段任务文案

## 8.2 `Train`

- 只放列车本体成长
- 主要模块：
  - `Locomotive`
  - `Main Gun`
  - `Armor Car`
  - `Support Car`
- 默认卡片只显示：
  - 图标
  - 名称
  - 当前等级
  - 战力贡献
  - 升级入口

## 8.3 `Crew`

- 只放乘员与岗位
- 屏内先展示 `3 个上阵位`
- 其余乘员通过横向卡列切换
- 点开后只显示：
  - 岗位偏向
  - 当前被动
  - 升级成本
  - 上阵 / 替换按钮

## 8.4 `Workshop`

- 只放永久研究
- 优先展示：
  - 当前收益
  - 下一等级收益
  - 当前成本
- 不做复杂科技树迷宫，优先 `6 条直线研究`

## 8.5 `Missions`

- 只放进度与领取
- 每项任务显示：
  - 图标
  - 短标题
  - 进度条
  - 奖励图标

## 8.6 `Season`

- 只放通行证轨道与赛季目标
- 主视图为：
  - 免费线
  - 高级线
  - 当前等级
  - 一键领取

## 8.7 `Shop`

- 分成两个区：
  - `免费 / 软货币`
  - `礼包 / 支付`
- 每个商品仅展示：
  - 图标
  - 价格
  - 3 个以内核心奖励图标
  - 1 条短标签

## 9. APP 单屏适配逻辑

## 9.1 总原则

- 每个页签默认 `一屏可理解、一屏可操作`
- 文本只用于：
  - 首次教学
  - 详情抽屉
  - 结算总结
- 平时靠 `图标 + 数字 + 短标签` 表达

## 9.2 战斗页屏幕分层

- 顶部 `10~12%`：压缩 HUD
- 中部 `72~76%`：完整战斗主场
- 底部 `12~16%`：技能与暂停操作

## 9.3 非战斗页屏幕分层

- 顶部 `8~10%`：资源条 + 页签标题
- 中部 `74~80%`：本页主功能
- 底部 `10~12%`：Tabbar

## 9.4 信息压缩原则

- 资源条只保留图标 + 数字
- “推荐战力 / 当前战力 / 差值”用 `3 个 chip` 展示
- 路线节点默认只展示 `图标 + 颜色`
- 奖励预览只放前 `3` 个核心奖励
- 长说明放在点击后的 `bottom sheet`

## 10. 列车成长系统拆解

## 10.1 列车模块

### `Locomotive`

- 决定基础耐久、推进速度、容错
- 是新手期最稳定的成长项

### `Main Gun`

- 决定主输出、清怪速度、Boss 破段效率
- 是中前期最直观的战力成长项

### `Armor Car`

- 决定护盾上限、减伤与生存手感
- 用于平衡“高火力但太脆”的构筑问题

### `Support Car`

- 决定修复效率、冷却缩减、回收辅助
- 是中后期把战斗节奏做顺的关键成长项

## 10.2 乘员岗位

- 初版建议 5 名乘员，战斗中上阵 3 名

| 岗位 | 作用方向 | 推荐体验 |
| --- | --- | --- |
| `Conductor` | 推进效率、事件收益 | 让局内路线选择更有差异 |
| `Gunner` | 主炮输出、暴击、超载收益 | 让输出成长更直观 |
| `Mechanic` | 修复、冷却、过热恢复 | 让容错不只靠血量堆叠 |
| `Scout` | 提前预警、精英处理 | 让战斗节奏更稳 |
| `Scavenger` | 资源收益、掉落增益 | 让长线成长更顺滑 |

## 10.3 永久研究

建议初版只做 6 条研究线：

| 研究线 | 核心效果 | 使用阶段 |
| --- | --- | --- |
| `Boiler Mesh` | 基础战力与车体上限 | 全阶段 |
| `Fire Director` | 主炮输出与超载效率 | 前中期 |
| `Plating Weld` | 护盾与减伤 | 前中后期 |
| `Repair Grid` | 修复效率与冷却缩减 | 中期 |
| `Salvage Charter` | Scrap / Fuel 收益 | 中后期 |
| `Relay Decoder` | Relay Data 收益与终极充能 | 后期 |

## 11. 内容模块清单

## 11.1 章节与关卡

- 初版建议 `4 章 x 6 关 = 24 关`
- 每章结构：
  - `4 普通关`
  - `1 精英关`
  - `1 Boss 关`

## 11.2 敌人与战斗内容

- 初版敌人分 5 类：
  - `冲锋车`
  - `远程炮台车`
  - `投掷兵`
  - `空投机`
  - `重甲精英`
- 初版 Boss 4 个：
  - `轨道掠夺王`
  - `燃炉巨蜥`
  - `信号暴君`
  - `黑门列车`

## 11.3 事件池

- 初版建议 `12~16` 个通用事件
- 每章再加 `2~3` 个主题事件

## 11.4 任务与赛季

- 每日 / 周期任务先围绕：
  - 通关次数
  - 修复次数
  - 终极技能释放
  - 击败精英
  - 升级模块
- 赛季奖励优先投放：
  - `Scrap`
  - `Fuel Cells`
  - `Core Chips`
  - 少量 `Relay Data`
  - 乘员碎片

## 12. 战斗节奏与压力节点设计

## 12.1 单局节奏模板

- `0~25 秒`：热身，快速理解攻击与护盾
- `25~60 秒`：第一次成型压力，鼓励第一次技能释放
- `60~100 秒`：第一次事件选择或三选一强化
- `100~150 秒`：精英压力，检验修复与护盾搭配
- `结尾 30~60 秒`：Boss 或终点爆发

## 12.2 内部压力节点

以下内容仅用于内部数值与支付设计，不直接面向用户暴露：

- `1-4`：第一次“修复与护盾”检定
- `1-6`：第一次 Boss 持续输出检定
- `2-3`：第一次“主炮 / 装甲 / 研究”三线资源分配检定
- `3-3`：第一次完整编组成型检定
- `4-2`：中后期多系统同步成长检定
- `4-4`：高阶研究与终极技能资源拉扯检定

设计目标不是生硬卡住玩家，而是：

- 让免费玩家通过活跃与整备也能继续推进
- 让小付费玩家更快补齐中期成长短板
- 让中付费玩家获得更顺滑的终盘成长曲线

## 13. 支付设计原则

- 付费不能直接替代玩法理解
- 付费优先解决：
  - 中期成长时间
  - 多资源并行压力
  - 后期研究效率
- 对用户可见的表述应使用：
  - `推进更稳`
  - `整备更顺`
  - `适合当前章节`
  - `更快组出完整编组`
- 不使用：
  - `卡点`
  - `逼氪`
  - `必须购买`

## 14. 运行时落地建议

本方案可以直接反推到未来的 `games/iron-frontier/iron-frontier.config.js`，建议配置结构如下：

1. `meta`
   - 游戏 id、标题、中英文名、资源定义
2. `tabs`
   - `run / train / crew / workshop / missions / season / shop`
3. `battleTune`
   - 波次时长、敌人密度、技能冷却、热量参数、Boss 轴
4. `stages`
   - `24` 关推荐战力、奖励、事件权重、Boss 定义
5. `trainModules`
   - 车头、主炮、装甲车、支援车定义与升级表
6. `crew`
   - 乘员属性、岗位、碎片与升级表
7. `research`
   - 六条研究线基础成本、成长曲线、上限
8. `missions`
   - 日常与周期任务
9. `season`
   - 免费线、高级线奖励
10. `shopOffers`
   - 软货币商品与免费补给
11. `paymentOffers`
   - 精确金额礼包、首购礼包、成长礼包
12. `uiDensity`
   - Run / Train / Crew / Shop / Battle 各页的单屏密度参数

## 15. 当前规划结论

`Iron Frontier` 适合作为 `Game 9` 的原因已经足够明确：

- 它能补上前 8 个游戏里缺少的 `经营调度型主体验`
- 它可以天然支持 `独立战斗页 + 单屏高密度整备页`
- 它非常适合做 `章节推进 + 站点事件 + 车厢模块成长 + 赛季 / 商店`
- 它的 UI 结构天然适合移动端 `少文本、重图标、强主场`

1. `docs/iron-frontier-progression-model.md`
